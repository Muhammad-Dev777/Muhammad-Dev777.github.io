# Muhammad Bhatti — Personal Portfolio

A responsive, static portfolio for academic and professional audiences. Built with HTML, CSS, and JavaScript; no installation or build step is required.

## Publish with GitHub Pages

1. Extract this ZIP. Upload the extracted files and the `assets` folder, not the ZIP itself.
2. In your **Muhammad-Dev777** GitHub account, create a public repository named **muhammad-dev777.github.io**.
3. Upload the contents of this folder to the repository and commit to `main`. Ensure `index.html` is at the repository root, alongside `styles.css`, `site.js`, and the `assets` folder. Include `.nojekyll` if your uploader displays it.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
5. After GitHub finishes publishing, your portfolio will be available at **https://muhammad-dev777.github.io/**. Publishing can take up to 10 minutes.

If you choose a different repository name, the address will instead be `https://muhammad-dev777.github.io/REPOSITORY-NAME/`. The site uses relative asset paths so both options work.

## Files and editing

- `index.html`: portfolio text, subjects, education, experience, and contact links.
- `styles.css`: responsive layout, typography, and colours.
- `site.js`: navigation highlighting and print action.
- `favicon.svg`: browser icon.
- `assets/portrait.jpg`: profile photo.
- `assets/Muhammad-Bhatti-CV.pdf`: downloadable CV.
- `.nojekyll`: tells GitHub Pages to serve the static files directly.

Open `index.html` in a browser to preview it locally. Edit the text in `index.html` to update your details. To update the CV or photo, replace the corresponding asset using the same filename. The CV download links already point to the included PDF.
